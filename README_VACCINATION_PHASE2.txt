VACCINATION PHASE 2 PATCH

Tujuan:
1. Print sticker benar-benar ukuran label, bukan page print biasa.
2. Session vaksinasi bisa link ke database corporate.
3. Registrasi vaksin bisa import peserta dari database corporate.
4. Default vaksin/lot dari session otomatis dipakai di registrasi dan administered.

Install:
1) Jalankan sql_vaccination_phase2.sql di Supabase SQL Editor.
2) Copy folder app ke root project Next.js.
3) npm run build
4) git add ...
5) git commit -m "add vaccination corporate import and label print"
6) git push origin feature/vaccination-module
